# Abbreviations

Abbreviations and acronyms used in this repository.

## Repo-specific terms

| Abbreviation | Full name |
| --- | --- |
| CDATA | Character Data (an unparsed-text XML section) |
| RFC | Request for Comments (IETF standards; RFC 822 defines the date format in RSS `pubDate`) |
| XXE | XML External Entity (an injection attack via XML parsers resolving external entities) |
